# Совет экспертов (council): раунды ревью

Три независимых ревьюера (Claude Opus 5.5, максимальное усилие, только чтение репозитория), каждый со своей линзой и навыком из `.claude/skills/`:
- **жюри** (`genesis-jury`) — повторяет критерии кейса (100 баллов) и запускает всё в Docker с нуля;
- **RL/ML red team** (`rl-env-grader-expert`) — контракт, обман награды, изоляция;
- **аудитор** (`audit-domain-expert`) — проводки, курсы, отсечение, однозначность эталона, пересчёт вручную.

Порог: все трое ≥ 9/10 в одном раунде. Любой blocker ограничивает оценку 5, major — 7.

## Путь жюри (UX council)

Отдельный совет из трёх ревьюеров проверял не среду, а путь жюри: от одной команды на чистой машине до оценки по пяти критериям. Ревьюеры запускали опубликованные команды из README на публичных URL в чистых контейнерах (`node:16/22/24/22-alpine`, Debian с curl, Ubuntu только с wget, Fedora, Alpine, Docker из git URL, macOS с новым HOME, ветка Windows через Docker и шаги PowerShell в pwsh 7), в папках с пробелом в имени, без сети после первого запуска и с обрывами загрузки. Порог тот же: все трое ≥ 9 в одном раунде.
